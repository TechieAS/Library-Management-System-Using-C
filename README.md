# 📚 Library Management System

## 📝 Overview
Welcome to the **Library Management System**, a simple yet efficient program written in C. This project allows users to manage a book collection by **adding**, **searching**, **borrowing**, **returning**, and **displaying books** through a menu-driven interface.

## 🛠️ System Requirements
Before running the program, ensure you have the following:
- **Operating System**: Windows, macOS, or Linux
- **Compiler**: GCC or any C-compatible compiler
- **Memory**: Minimum 512MB RAM
- **Storage**: Minimal disk space (text-based storage)

## 🚀 Features
✅ **Add a Book** – Store book title, author, and ISBN  
🔎 **Search for a Book** – Find books by title or author  
📖 **Borrow a Book** – Check out a book if it's available  
♻️ **Return a Book** – Return borrowed books  
📜 **Display All Books** – View all books currently in the system  
❌ **Exit** – Quit the program gracefully
